# CLI Password Generator
## ZEON-07

Pre-requisites
- JAVA SDK
- GO (Optional)
- Rust (Optional)

## Running The Application

### Java

To Compile Java
> `javac main.java`

To Run The Program

> `java main`

### Go

PreReq
> `cd go && go mod`

to Run
> `go run .`

### Rust
PreReq
> `cd rust`

to Run

> `cargo run`
